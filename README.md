# 문제 생성 플랫폼



## 개요

---

LLM 기반 문제 생성 플랫폼

### 기능

- 사용자는 자신이 정리한 개념 정리노트를 기반으로 문제를 생성한다.
- 생성한 문제를 풀어보고 채점할 수 있다.
- 생성한 문제를 다른 사용자들과 커뮤니티를 통해 공유할 수 있다.
